# make-cartoon-content

> **Setup first.** Values come from `~/.config/reel-studio/config.json` (written by `studio-setup`): `$STUDIO` = `studio_dir`, `$PLUGIN` = `plugin_root`, `{creator_name}`, `{brand}`, `{drive_remote}`, `{drive_folder}`. Channel rules and approval gates live in `$STUDIO/CHANNEL_RULES.md`.

> The bundled `template/cartoon/rig/avi_art.svg` is the author's own cartoon, shipped as a working example. Bring your own image to replace it (see *Character*).


the creator gives a **topic** (and later a **voiceover file**); this skill does everything else. The look is the format of a reference account studied with the `study:` mode: paper background, one "stage" object per idea in the upper middle, a cartoon host at the bottom who gestures on the beat, big word-by-word captions with one serif-italic accent word, small mono kicker line (`// 03 · one tick`), numbered progress, stamps and counters for the twist. Everything is code-rendered, so it is razor sharp (no camera blur) and costs nothing.

`T = $PLUGIN/template/` (copied to `$STUDIO/template/` by `studio-setup`) · `C = T/cartoon/` · projects live in `$STUDIO/cartoons/<name>/`.

## Hard rules
- **Open source only:** ffmpeg, whisper.cpp (word timings), HyperFrames (Apache-2.0, HTML → MP4), plain SVG/CSS, Google Fonts under OFL (Archivo, Instrument Serif, JetBrains Mono), SFX from `T/composition/assets/audio/sfx` (generated by `make_sfx.py`), music from the YouTube Audio Library only ("Attribution not required", picked automatically by `pick_music.py`, standing OK). No paid avatar/voice/video services, no AI-generated video. **GSAP** is used only as the timeline clock: it is free under GSAP's own "no charge" licence but is not OSI open source; say so if asked, and swap it for Anime.js (MIT) if the creator wants strictly OSI.
- Same channel rules as `reel-script` (25–32 s, 70–95 words, payoff-first hook, no jargon in the first 10 s, a debatable yes/no question at the twist and again at the end, loop line). Run `script_lint.py` on the script.
- Never put real people's faces/likeness other than the creator's own cartoon; never copy another creator's character art.
- Approval gates from `$STUDIO/CHANNEL_RULES.md` stay: Studio/draft preview approved before the final render; Drive upload (new subfolder of `{drive_folder}`) only after the creator approves the video AND the cover; ask when a sign-in is needed.

## Workflow
1. **Script** (topic only): follow `reel-script` sections 1–5 with these cartoon changes: 60–85 words; each sentence = one scene = one picture; write the topic as `<familiar product> + <surprising limit>`; hooks A claim / B contradiction / C anti-hook. Save `script.md`, run `script_lint.py` until PASS. Tell the creator: "Record this as a voice note (phone, quiet room, 10 cm from the mouth), send the original file (AirDrop), then say `voice ready`." Recording tips go in the message, not a long sheet.
2. **Voice in:** save as `cartoons/<name>/voice.<ext>`. Check it: `ffprobe` (≥ 44.1 kHz, no clipping); if noisy, apply the VOICE chain from `T/scripts/make_cut.py` (highpass, afftdn, presence EQ, compressor). Do not upscale a 8 kHz phone-call file: ask for a re-record.
3. **Storyboard:** `python3 -I C/build_cartoon.py <project> --transcribe` prints every word with its start time (and writes `assets/words.json`). Write `scenes.json` from it (below): one scene per sentence, 1.4–3.5 s each, a scene starts on the first spoken word of its sentence.
4. **Build:** `python3 -I C/build_cartoon.py <project> --music` → `index.html` (voice, mouth shapes from the audio, SFX cues, bgm with a voice carve) + HyperFrames scaffold.
5. **Check:** `cd <project> && npx --yes hyperframes@0.8.209 check` (0 errors; the "closing line on screen < 2 s" warning is fine for a loop ending, but hold the last stage object until the last word).
6. **Draft + QA:** `npx --yes hyperframes@0.8.209 render -o renders/draft.mp4 -q draft`, then a contact sheet (one frame per scene midpoint, `ffmpeg … hstack`) and LOOK at it: stage centred and not overlapping the head (stage band y 440–1130, head y 1180–1620), caption never covers the stage, mouth opens on speech, poses vary (no two scenes in a row with the same pose), every scene has a visible change. Fix and re-render; max 3 rounds.
7. **Checkpoint (one message):** Studio preview (`npx hyperframes preview`) or the draft path, the contact sheet, cover, posting kit, and the one open question if any. Wait for approval.
8. **Final render:** `npx --yes hyperframes@0.8.209 render -o renders/final.mp4 -q delivery -f 30` then `T/scripts/finalize.sh renders/final.mp4 renders/<name>_final.mp4` (−14 LUFS). ffprobe: 1080×1920, 30 fps, H.264, audio present.
9. **Cover:** the frame at the hook scene's peak (≈ 1.0–1.5 s) already carries the big hook word: `ffmpeg -ss <t> -i final.mp4 -frames:v 1 -q:v 2 covers/cover_a.jpg`; B = the stamp/counter scene frame. Check `covers/grid_check.png` crop (3:4, y 240–1680). Never a cover without a headline.
10. **Posting kit + Drive:** `T/posting-kit-template.md` (title = `<claim> | <keyword>`, no hashtags in the title, 3–5 specific hashtags in the caption, pinned comment, Trial Reel plan for hook A vs C). After approval: `rclone` to `{drive_remote}:{drive_folder}/<name>/` (always a NEW subfolder), size-verified. Log the reel in `$STUDIO/reels/style_log.md` (format = Cartoon).

## scenes.json
```json
{"title": "One tick", "character": {"skin": "#d6a07a", "hair": "#15120f", "tee": "#252b33", "beard": true},
 "scenes": [
  {"from": 0.0, "to": 1.55, "pose": "point", "kicker": "// 01 · the claim",
   "stage": {"type": "phone", "lines": [{"who": "me", "text": "Where are you?", "tick": "✓"}]}},
  {"from": 1.55, "to": 3.35, "pose": "shrug", "kicker": "// 02 · the myth", "stage": {"type": "big", "text": "*Not*\nignored"}, "accent": ["ignored"]}]}
```
- **stage.type:** `big` (huge word, `*accent*` in serif italic) · `card` (title + body) · `phone` (chat lines; `who: me|them`, optional `tick`) · `terminal` (lines typed in) · `checklist` (items tick one by one, check-blip SFX) · `flow` (nodes joined by arrows, appear in order) · `counter` (`from`,`to`,`prefix`,`suffix`,`label`; rolls up) · `stamp` (slams in with a heavy hit; use for the twist/verdict). No stage = host only (use sparingly, for a reaction beat).
- **pose:** `rest` · `explain` (open palm up) · `point` · `count` (finger up) · `shrug` · `think` (fist to chin) · `both` · `cheer`. Pick the pose that matches the sentence; change it at every scene.
- **accent:** words in that scene's lines that show as serif italic in the accent colour in the captions (1–2 per scene, the meaning words).
- Every scene may add `"sfx": [["pop", 4.2, 0.3]]`. The builder already adds a pop per stage, a paper-slide per scene change, check-blips and a heavy hit on stamps.

## Scene rules (from the references)
- Hook scene is a big visual in the first 1.5 s (`big`, `phone` or `stamp`) while the hook is spoken; the host points at it. No title card, no greeting.
- One idea per stage object, one change every 1.5–3 s; the twist scene is a `stamp` or `counter`; the CTA scene is `big` with the yes/no question, held to the last word.
- Kicker numbering `// 01 · the claim` … it is the visible progress bar. Keep scenes 5–8 total.
- Captions are the second story: never repeat the same sentence in the stage text; the stage shows the picture, captions carry the words.

## Character (production rig, v3)
The host is **the creator's own cartoon** (your own cartoon image), rebuilt as a puppet in `T/cartoon/engine.js`:
- **Head** = the original art, cut out (`rig/mask_person.py`, flood-fill by outlined region from `rig/seeds.json`, no ML) and vector-traced with vtracer (MIT). Rebuild with `/tmp/vt/bin/python T/cartoon/rig/make_art.py <your cartoon image>` (needs `python3 -m venv /tmp/vt && /tmp/vt/bin/pip install vtracer`; vtracer only runs with default arguments on Python 3.15). The traced eyes and brows are deleted from the art and redrawn live, so they can blink, look and lift.
- **Body** = drawn in code to match the cartoon (torso, collar, shirt text, thick #2b2321 outline): two real **jointed arms** (sleeve > forearm > wrist > hand), mirrored for the left side. Poses are **joint angles** (`rest, explain, point, count, shrug, think, cheer, both, wave`), and `think` uses **two-bone IK** (`ik("R", x, y)`) so the hand lands on an exact point. Add a pose = one line in `POSES`; aim a hand at something = `ik()`.
- **Animation principles built in:** anticipation (small pull-back), shoulder leads / elbow +0.06 s / wrist +0.12 s with overshoot, head tilts a beat late (follow-through), body lift on shrug/cheer, breathing, blinks (some double), slow head sway, eyes glance up at each new stage object, brows lift and head nods on accent words.
- **Lip-sync:** `build_cartoon.py` → `lipsync()`: whisper word timings, letter-to-shape mapping (A closed, B slit, C mid, D wide, E round, F pucker, G teeth-on-lip, H tongue, X = the cartoon's own smile), loudness correction, 50 ms minimum hold. For the real voice: run the builder on it, then watch the draft with sound before approving. Rhubarb Lip Sync (MIT) would be more exact, but downloading its binary was blocked by the permission check: only use it if the creator allows that download.
To change the look: new sticker image, new `seeds.json` (one seed per outlined region, never on the white halo), re-run `make_art.py`, adjust the body constants.

## Known limits
Lip-sync is word-timing based, not phoneme-exact. The lower body is a plain tee that runs off-frame. Hands are drawn mittens (open / point / fist). Stage cards are code-drawn approximations of real UIs: for real products use a screenshot inside a `card`.

## Extend
New stage type = one entry in `S` (markup), CSS in `build_cartoon.py`, and an `inner()` branch if it animates over time. New theme = the CSS variables at the top of `CSS`. Keep every motion on the single `tl` timeline (seek-safe: no `repeat:-1`, no random at runtime).
