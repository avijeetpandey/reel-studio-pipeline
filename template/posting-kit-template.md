## Rules (keep in mind while filling)
- Patterns from the reference reels: `$STUDIO/template/WINNING_PATTERNS.md` §8 (caption = hook line → full list as text → trust line → CTA → 3–5 product + niche tags like #claude #claudeai #claudecode #aitools).
- Instagram: **max 5 hashtags** (caption + comments share the cap). Mix = 3 on-topic (1 broad searchable,
  1 format/category, 1 exact-topic niche) + 2 adjacent trending tech tags. Never #ai, #fyp, #reels, #explorepage.
- Keywords matter more than hashtags: put the search phrase in the first caption line, the alt text and
  a plain-text keyword line (trending terms as words, not hashtags).
- Strongest signals: sends/shares, watch time, saves, comments → caption ends with save / send / comment CTAs.
- YouTube: keyword-first title ≤ 60 chars, 3 description hashtags (shown above title), Tags field ≤ 500 chars,
  upload the .srt, category Science & Technology, not made for kids. No #Shorts needed.
- Post the same clean master to both platforms (never a re-download with a watermark).
- Timing (your audience — set in CHANNEL_RULES.md): **one reel per day at a fixed slot** — Instagram 7–9 PM (your timezone), YouTube 12–2 PM (your timezone).
  Never two uploads on the same platform within 12 h, never between 11 PM and 9 AM (your timezone). Check Insights.
- Comment CTA = a one-word / yes-no debatable question. No "comment KEYWORD for the snippet" until the
  account has an audience (week-1: 0 comments from keyword CTAs).
- YouTube title: **no hashtags in the title**; phrase it like a search query ("How does ChatGPT …?").
- Before publishing, re-read Tags/keywords and hashtags: they must be THIS reel's (week 1 shipped the
  Claude Code Short with the image-reel's tags). No duplicate hashtags.

- [ ] 48 h later: log YT stayed-to-watch %, avg % viewed, IG views / shares / saves in the reel folder.
